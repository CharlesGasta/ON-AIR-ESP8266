# ON AIR ESP8266 v3.1.0 — Studio mobile

Une nouvelle interface pour le logo Damien : une console de diffusion conçue d'abord pour le téléphone, entièrement embarquée et utilisable sans Internet.

## Installation

Télécharger **ON_AIR_ESP8266_OTA.bin**, puis l'envoyer depuis l'ancienne interface : **Paramètres → MISE A JOUR FIRMWARE OTA**. Après redémarrage, recharger la page pour recevoir la nouvelle interface.

Dans la nouvelle interface : **Réglages → Système & maintenance → Mettre à jour le boîtier**.

## Ce qui change

- Quatre cartes d'émission avec logos, couleur, intensité et durée d'alerte ; disposition adaptée au téléphone et au bureau.
- État DIRECT, HORS DIRECT et ALERTE explicite, avec confirmation reçue du boîtier.
- OFF / NOIR disponible en permanence dans la console, y compris pendant une alerte.
- Perte de connexion indiquée clairement ; aucune commande rejouée automatiquement.
- Réglages des émissions en premier, installation et maintenance rangées dans des rubriques repliables.
- Éditeur d'émission organisé : direct, hors direct, alerte et identité visuelle.
- Sauvegardes séquencées pour conserver la dernière modification lors des changements rapides ; message d'erreur et possibilité de réessayer. Le test d'alerte ne démarre pas si la sauvegarde échoue.
- Écran OTA mobile avec progression et distinction entre succès et erreur d'installation.
- Aucune police, bibliothèque ou image téléchargée sur Internet par le boîtier.

## Compatibilité

NodeMCU ESP8266 / ESP-12E, **36 WS2812E**, sortie D5/GPIO14, luminosité autorisée jusqu'à **100 %**. Moteur LED, animations, commandes, Wi-Fi, portail captif et format des paramètres EEPROM / LittleFS conservés. Mise à jour du programme uniquement : pas de remise à zéro ni de flashage du système de fichiers.

## Validation

Comparaison du code avec la v3.0.4 : moteur LED, structures, migrations, valeurs par défaut, gestionnaires existants et boucle inchangés. Tests navigateur sur largeurs 320, 390, 430, 768 et 1440 px : commandes, verrouillages, coupure/reconnexion, navigation, scan Wi-Fi simulé, sauvegarde rapide/échec/reprise et réponses OTA simulées. Compilation réelle et publication via GitHub Actions. Les tests navigateur utilisent un boîtier simulé ; aucune validation physique du nouveau firmware n'est revendiquée.

## À propos des anciens redémarrages

La comparaison v3.0.2 → v3.0.4 montre que le seul changement de code exécutable, hors version, est la constante de luminosité 25 → 100. Le plafonnement effectue un minimum et une mise à l'échelle des couleurs ; aucun redémarrage ou traitement particulier n'est déclenché au-delà de 25 %. Cela ne permet pas d'attribuer rétrospectivement les redémarrages à une cause précise. La rubrique Diagnostic permet de lire le motif du dernier reset si le phénomène réapparaît.

## Montage utilisateur

L'utilisateur rapporte un ruban à 1,02 A en blanc 100 % sur alimentation de laboratoire, puis un montage stable via USB-C / VV, sans échauffement constaté après plusieurs minutes et essais d'allumage/extinction. L'architecture est conservée. La mesure de 1,02 A concerne le ruban seul et ne constitue pas une spécification de courant admissible de VV.
