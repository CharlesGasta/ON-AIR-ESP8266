# ON AIR ESP8266 v3.2.0 — Thèmes et animations spatiales

## Installation

Installer **ON_AIR_ESP8266_OTA.bin** depuis Réglages → Système & maintenance → Mettre à jour le boîtier. Recharger l'interface après redémarrage. Réglages, Wi-Fi, couleurs, noms et logos existants sont conservés ; les nouveaux effets DIRECT sont **Fixe** par défaut.

## Clair / sombre

Réglages → Apparence → Clair ou Sombre. Le choix est mémorisé dans ce navigateur pour cette adresse du boîtier. Sans préférence enregistrée, le thème suit l'apparence du téléphone. Les pages console, réglages, émission, diagnostic et mise à jour utilisent le même thème.

## Animations en DIRECT

Dans les réglages de chaque émission, choisir **Animation en direct** et **Durée d'un cycle** (1 à 12 secondes) : fixe, respiration, balayage gauche → droite, droite → gauche, comète autour du logo, aller-retour, arc-en-ciel horizontal ou ouverture depuis le centre. La couleur de l'émission est conservée, sauf en mode arc-en-ciel. L'intensité de l'émission reste le maximum ; la respiration descend à 15 % de ce maximum.

Les sept alertes existantes sont conservées, avec cinq ajouts : balayage gauche → droite, droite → gauche, respiration, ouverture centrale et arc-en-ciel. L'alerte respecte toujours sa durée puis passe au DIRECT configuré. Le test d'alerte se termine toujours au noir.

## Disposition confirmée, vue de face

| Partie | Indices | Sens |
|---|---|---|
| Bas | 0–11, 12 LED | droite → gauche, départ sous le R |
| Gauche | 12–16, 5 LED | bas → haut |
| Haut | 17–30, 14 LED | gauche → droite |
| Droite | 31–35, 5 LED | haut → bas |

Les coordonnées sont normalisées par côté : les LED du haut et du bas sont alignées selon leur position horizontale, malgré leurs nombres différents. Les positions exactes en millimètres ne sont pas supposées.

## Démarrage

Cinématique de 4,5 secondes : balayage arc-en-ciel gauche → droite, flash blanc de 60 ms, montée progressive du blanc, expansion rouge depuis le centre, plateau rouge puis extinction. Ensuite :

- Comète bleue : point d'accès local en création / disponible.
- Balayage orange : tentative Wi-Fi externe, pendant au plus 15 secondes depuis le début de la séquence.
- Trois validations vertes : connexion externe réussie.
- Trois signaux orange : Wi-Fi externe non trouvé, puis respiration bleue indiquant l'accès autonome pour configurer le boîtier.
- Rouge : échec du point d'accès local, distinct d'un simple réseau externe absent.
- Sans Wi-Fi externe activé ou mémorisé : mode autonome bleu, sans fausse erreur.

La cinématique se désactive avec l'option de démarrage existante. Son test reste disponible indépendamment de cette option et est refusé pendant un vrai DIRECT ou une alerte. Une commande DIRECT, ALERTE, aperçu ou OFF interrompt le démarrage ; OFF ne peut pas être suivi d'une reprise automatique de l'animation.

## Sauvegardes et validation

Le format EEPROM historique est inchangé. Les nouvelles options d'animation sont enregistrées séparément dans LittleFS avec contrôle d'intégrité et remplacement du fichier après écriture complète. Les exports de configuration V2 incluent les animations. Les anciens backups V1 restent importables ; ils rétablissent les nouvelles animations sur Fixe.

Le moteur est testé en C++ hôte avant compilation : géométrie, directions, plafonds, phases de démarrage, réussite/échec Wi-Fi, priorité des commandes, persistance et imports V1/V2/corrompus. Les tests navigateur vérifient les thèmes et les contrôles. Les essais utilisent des adaptateurs matériels simulés ; la validation visuelle sur le ruban reste à faire après installation.
