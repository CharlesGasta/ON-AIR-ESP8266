# ON AIR ESP8266 3.5.0 — Atelier d’animations

- Contour progressif : un tour pour allumer, puis un tour pour éteindre, sans extinction brutale.
- Un balayage aller-retour par axe ; haut/bas seuls pour l’horizontal, côtés seuls pour le vertical. Anciens identifiants sauvegardés toujours acceptés.
- Palette 13 couleurs et intensité globale de séquence 0–100 %, mémorisée avec l’animation.
- Banque : modèles prêts à modifier, rappel d’une animation enregistrée, copie indépendante pour créer une variante.
- Chaque étape peut être une image LED, un chenillard (départ/arrivée/vitesse) ou un flash/strobe sur les LED choisies (intervalle 20–10000 ms).
- LED sélectionnables au centre en souris/tactile, zones fixes indépendantes de l’animation des boutons.
- Grand logo vectoriel inspiré du boîtier photographié avec simulation de diffusion colorée dans les lettres. Simulation indicative, pas une mesure optique.

EEPROM et configuration inchangées ; anciennes animations .onair version 1 toujours lisibles. Le format CUE1 version 2 conserve la taille de 1356 octets et le checksum, ajoute l’intensité et les outils procéduraux. Ces nouvelles animations nécessitent le firmware 3.5.0 ou ultérieur ; elles ne sont pas lisibles par un ancien firmware. Aucun nouveau tableau permanent de couleurs sur l’ESP.

Cinématique de démarrage, arc-en-ciel horizontal, effets classiques et luminosité maximale conservés. Test de compilation et tests automatisés ne remplacent pas une validation matérielle de cette version.

OTA : ON_AIR_ESP8266_OTA.bin.
